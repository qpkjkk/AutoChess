## 分刀（每刀独立验收，绿灯才进下一刀）

### 刀 1：平台接口化（最小侵入）
- 新建 `core/Platform.kt`：`interface Clock { fun now(): Long }` + `interface Scheduler { fun postDelayed(ms: Long, action: () -> Unit); fun post(action: () -> Unit) }`
- AutoPlayService.kt 内部引用换接口（31 个 android import 中的 Handler/SystemClock 依赖全走 Platform）
- **验收**：APK 编译过+构建产物 bit 级不变的行为（无逻辑改动，纯替换）

### 刀 2：状态机核抽出
- `core/AutoPlayCore.kt`：tick 循环+7 态（CONNECTING/WATCH/THINK/PLAY/NEW_GAME_SYNC/IDLE/...）+三盘副本（extBoard/clickAfter b2/anchor）+verify 闭环（① ② ③ ④ 双帧确认）+烂帧门+重置链
- 输入抽象：`fun onFrame(occ: String, whiteAtBottom: Boolean)`（识别帧）；输出抽象：`fun onClick(from: Pair<Int,Int>, to: Pair<Int,Int>)` + `onStatus(text: String)`（状态上屏）
- **验收**：core 模块 0 android import（编译期强制）；APK 引用后行为基线零偏移

### 刀 3：stdin/stdout JSON 协议
